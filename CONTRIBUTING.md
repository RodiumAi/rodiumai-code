# Contributing

This repository is the public issue tracker and documentation home of the RodiumAi developer products. It does not contain source code, so there is no code to submit here. The most useful contribution is a clear issue.

## Before you open an issue

- Search the [existing issues](../../issues), including closed ones. Add a comment or a reaction to an existing issue instead of opening a duplicate.
- Check the [troubleshooting guide](https://www.rodiumai.io/docs/code/troubleshooting).
- Use the latest version of the product if you can.
- One problem per issue. It makes each one easier to find and to close.

## Pick the right form

| You want to | Use |
| --- | --- |
| Report something that does not work | The **Bug report** form |
| Suggest a change or a new capability | The **Feature request** form |
| Report a documentation error or a missing explanation | The **Bug report** form, with the product set to the one concerned and the page in the description |
| Report a security vulnerability | Not an issue: see [SECURITY.md](SECURITY.md) |
| Ask about your account, a payment or a plan | [RodiumAi support](https://www.rodiumai.io/dashboard/support) |

## What a good bug report contains

- The product and its version.
- Your operating system and its version, and the processor type (Intel, Apple Silicon, ARM).
- What you did, step by step, so that we can do the same.
- What you expected and what happened instead.
- The exact error text, copied rather than retyped. A screenshot helps for visual problems.
- The product-specific details listed in its own guide: [CLI](cli/CONTRIBUTING.md), [Desktop](desktop/CONTRIBUTING.md), [VS Code and Cursor extension](vscode/CONTRIBUTING.md), [MCP server](mcp/CONTRIBUTING.md).

## Never post

An issue is public and stays public. Before you send it, remove:

- RodiumAi API keys (they start with `rd_sk_`), tokens, passwords and any other secret.
- Personal data: your email address, phone number, payment details, and the names or contents of private files and projects.
- Anything you are not allowed to share, such as private source code or customer data.

If you posted a secret by mistake, revoke it in your dashboard right away. Editing or deleting the issue does not remove it from the history that others may already have seen.

## What happens next

We read the issues and label them by product and by kind. We cannot promise a delay or a fix for every report, and a feature request is a suggestion, not a commitment. We may ask you for more details, and we close an issue that stays without an answer from the reporter.

## Behaviour

Be respectful and keep to the subject. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
