# Security policy

## Report a vulnerability

Please do not report a security vulnerability in a public issue, a discussion or a pull request.

Send the report by email to **security@rodiumai.io** and include:

- The product and its version.
- A description of the vulnerability and of its impact.
- The steps to reproduce it, or a minimal proof of concept.
- How we can reach you.

We will acknowledge your report and keep you informed of the progress. Please give us a reasonable time to fix the problem before you share the details publicly.

## What is covered

The RodiumAi Code CLI, the RodiumAi Code Desktop app, the RodiumAi Code extension for VS Code and Cursor, the RodiumAi MCP server, and the RodiumAi website and API.

## Secrets

If you find a RodiumAi API key (`rd_sk_...`) that has leaked, anywhere, revoke it in your dashboard. If it is not yours, tell us at security@rodiumai.io.
