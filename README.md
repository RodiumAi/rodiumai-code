# RodiumAi Code and developer tools

The public home of the documentation and of the issue tracker for the RodiumAi developer products.

This repository contains no source code. It explains what each product does, how to use it, and it is the place to report a bug or ask for a feature.

## Products

| Product | What it is | Status | Folder |
| --- | --- | --- | --- |
| RodiumAi Code CLI | The RodiumAi Code agent in your terminal, with the `rodium` command | Not public yet. [Join the waitlist](https://www.rodiumai.io/code) | [cli](cli) |
| RodiumAi Code Desktop | The RodiumAi Code agent as a native app for macOS, Windows and Linux | Not public yet. [Join the waitlist](https://www.rodiumai.io/code) | [desktop](desktop) |
| RodiumAi Code for VS Code and Cursor | The RodiumAi Code agent in an editor tab | Available on the [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=rodiumai.rodiumai-code) and on [Open VSX](https://open-vsx.org/extension/rodiumai/rodiumai-code) | [vscode](vscode) |
| RodiumAi MCP server | The RodiumAi API inside your AI assistant | Available on [npm](https://www.npmjs.com/package/rodiumai-mcp) | [mcp](mcp) |

The three RodiumAi Code products share the same agent, the same account and the same FRODI allowance. The MCP server uses a RodiumAi API key and the RODI wallet.

## Report a problem or ask for a feature

1. Search the [existing issues](../../issues) first.
2. Open a [new issue](../../issues/new/choose) and pick the form that fits.
3. Read [CONTRIBUTING.md](CONTRIBUTING.md) to know what to include, and what to never post.

Questions about your account, a payment or a plan are better handled by [RodiumAi support](https://www.rodiumai.io/dashboard/support), because they need your account.

## Security

Do not report a vulnerability in a public issue. See [SECURITY.md](SECURITY.md).
